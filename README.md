# Sudoku Solver & Generator

A Python-based Sudoku application that generates random boards, validates board constraints, and solves puzzles step-by-step using constraint propagation and user interaction.

## Features
- **Board Generation:** Generates valid, randomized Sudoku starting boards.
- **Deduction & Validation:** Verifies rows, columns, and 3x3 sub-grids for validity.
- **Interactive Solver:** Automatically fills cells with unique choices and prompts the user when multiple candidate numbers exist.
- **File Export:** Writes puzzle states and final solutions to a text report.

## Getting Started
Run the solver using Python 3:
```bash
python sudoku_solver.py
```
